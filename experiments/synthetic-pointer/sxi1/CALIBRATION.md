# Synthetic source and W+ positive-control calibration

**Exploratory, one lineage in world `S05W9403`.** This calibration preceded the prospective SXI-1 holdout. It uses a source and a repair controller that were deliberately programmed, not an independently discovered organisation.

The two equal-size interface arrangements resolve to different synthetic source addresses. Their known cyclic output programs have the same four labels and counts in different order. The sources are finite-state fixtures with a stored target ring and a rule that restores one altered slot per block. A local test deliberately damaged two slots and verified the programmed restoration. This is source-internal repair; it is not transfer of repair to Amelia.

The source outputs were frozen and delivered through the W+ pointer to the verified INGRESS-1 runtime. Source A, source B, shuffled, rapidly mixed and sham traces all passed independent verification. A and B had identical transitions and state digests for the first 500 ticks and first differed in destination at tick 559. This is one fixture's response to different programmed sources, not evidence of an external mind or a population effect.

For the separate W+ positive control, source A had already been withdrawn when the 30 entries of the recent house `S` were each increased by 0.1.
