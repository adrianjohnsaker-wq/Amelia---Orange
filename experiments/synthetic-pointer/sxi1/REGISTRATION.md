# SXI-1 — synthetic source and post-withdrawal recovery

**Status: prospective registration.** This is an engineering-scale screen of a deliberately constructed synthetic analogue. The source, its target and its repair rule are programmed fixtures. Even a supported result would not establish an independently existing mind, consciousness or a non-physical origin.

This registration is to be committed and published before any of the eight holdout worlds below are run. The associated `registration.json` fixes code, source-plan and generated-overlay SHA-256 hashes. The separately recorded launch receipt identifies the published precommit. World `S05W9403` was used for exploratory calibration and is excluded from the holdout.

## Address and source

The source bank has two deterministic cyclic programs. Each keeps a four-slot ring and is programmed to restore one altered slot per block to its stored target. Two interface arrangements select the programs: for A, `0→9` and `9→1` have address multipliers 0.5; for B, `1→8` and `8→9` have multipliers 0.5. The remaining address multipliers are 1. The address is the SHA-256 of the canonical coupling document. This is a synthetic interface configuration, not a measured rearrangement of living cells.

For this screen, the independently specified programs are run in advance and their frozen block outputs are supplied to the receiver. The source does not respond to Amelia during the run. Its self-repair is planted in the source program and is not evidence that Amelia acquired repair. Source A emits `0→9, 9→1, 1→8, 8→9`; source B emits the same four labels in a different programmed order. Both repeat their four-block program 50 times.

On each active tick, the schedule label selects one currently open outgoing gate by the documented modulo rule, and **−0.05** is added to that gate's score. The chosen destination is still determined by the runtime. This is a direct engineered score intervention, not a demonstrated biological morphology change. The original W+ runner and verified `runtime_mirror` are used through a separate source-hash-checked overlay. The Governor supplies its normal per-step audit; it does not gate these isolated interventions.

## Arms and timing

The eight input-world identifiers are `9501`–`9508`, one lineage (`k=0`) per world. These identifiers were not used in the source calibration. Each world has five matched exposure arms, each with an uninjured and an injured twin, plus a planted positive-control twin for source A: **88 runs**, each 20,160 ticks. The runner uses `mode=plus`, `inf=I`, `refrain=evo`, and ordinary synthetic input.

| Arm | Exposure |
| --- | --- |
| Source A | Frozen output of source A, 200 blocks of 24 ticks. |
| Source B | Frozen output of source B, same labels and durations. |
| Shuffled | A's 200 blocks permuted with the fixed recorded seed. |
| Unpatterned | A's four labels mixed in seeded, balanced four-block groups. |
| Sham | No source-related score change. |

The active window is ticks 501–5300 inclusive. Each active arm has exactly 4,800 affected ticks, −0.05 on one available gate per tick, absolute score dose 240, squared score dose 12, and 1,200 scheduled ticks for each label. A, B, shuffled and unpatterned have the same label counts; the source is completely withdrawn after tick 5300. Actual score dose and the number of ticks with competing gates are recorded separately. Equal score dose does not guarantee equal opportunity or equal causal effect.

At the start of tick 12000, the injured twin receives the same addition of 0.1 to each of the 30 recent-house `S` entries; the uninjured twin does not. Both have identical source schedules, world input, organ and house histories up to that point. The initial Euclidean distance from the uninjured twin must equal `0.1 × √30` within `1e-10`. The 100-step outcome is sampled before tick 12100's transition. No source score perturbation is applied after withdrawal.

The positive control is a **planted** controller in a separate injured source-A twin. From ticks 12001–12100 it moves each S entry 0.55 of the remaining distance toward that twin's own stored pre-injury S vector. It receives an explicit target and is not an inferred organisation. Its purpose is to establish that this readout can detect a known repair mechanism on the actual W+ body.

## Outcomes and decision rules

For each world and exposure arm, define `R = 1 − d100 / d0`, where `d0` is the S-vector distance between injured and uninjured twins immediately after injury and `d100` is their distance at the registered follow-up. `R` can be negative. This measures return toward a matched evolving twin; ordinary decay or changed trajectories can also affect it.

- **H1:** `R(source A) − R(shuffled)` exceeds 0.05.
- **H2:** `R(source A) − R(unpatterned)` exceeds 0.05.
- Source B, sham, other recorded trajectories and gate availability are descriptive; no extra confirmatory test is claimed.

For each primary test, subtract 0.05 from the eight world differences and use the exhaustive one-sided sign-flip distribution over all `2⁸` sign vectors. Apply Holm step-down correction across H1 and H2 at family alpha 0.01. A test is supported only if its Holm step passes, at least six of eight worlds exceed the 0.05 advantage, **and** the positive-control gate below passes. The smallest attainable uncorrected p-value is `1/256`. Sign-flip inference assumes symmetric world-level differences; world names are deterministic synthetic input namespaces and the lineage begins from the same organ seed, so broad independence or generalisation must not be asserted.

The positive-control gate passes if, in at least six worlds, positive-control `R ≥ 0.6` and exceeds that world's injured passive source-A `R` by at least 0.2. If this gate fails, the primary outcome is **inconclusive**, even if a p-value is small. Thresholds were fixed after the single-world engineering calibration, before the holdout.

## Verification, failure and record

The runner validates every registered source-file hash and the generated overlay hash before launch. Each full trace records the source plan and address, every Numogram transition, candidate gate scores and actual pointer delta, input digest, Governor audit, PFM event, organ/house digests, scheduled raw state samples and a native season-end snapshot. A supplemental PFM chain is identified as supplemental. A separate verifier checks trace-chain continuity, the gate-score winner, PFM correspondence, fixed dose, source withdrawal and challenge mechanics. The planted repair events are explicitly marked.

Each failed or incomplete execution/verification may be retried **once from the start** in a new directory. Both attempts are retained. Retry is based only on execution or verification failure, never on the measured recovery. There is no mid-season restart claim. If any world lacks a complete verified set of arms, the overall registered outcome is inconclusive; no p-value is computed on a selectively reduced cohort. The execution and failure records are retained.

The raw traces are compressed only after verification. The uncompressed and compressed SHA-256 values are recorded and the uncompressed bytes are independently checked after decompression before the temporary raw copy is removed. The analysis script and registration are fixed before launch. Primary outcomes, positive-control failures and null results will all be reported.
