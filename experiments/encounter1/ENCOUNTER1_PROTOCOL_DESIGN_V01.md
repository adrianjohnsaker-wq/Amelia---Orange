# ENCOUNTER-1 — Does an Outside encounter change Amelia's future capacities?

**Protocol design candidate · 26 October 2026 · NOT REGISTERED · NO SCIENCE RUN**

## Hypothesis

Can an incoming event change the coupled Amelia–house system so that a **new, durable capacity** is available at a later encounter? The test distinguishes (a) an immediate reaction, (b) transient or destructive disruption, and (c) a persistent, causally incorporated developmental change.

This is **not** an experiment purporting to verify CCRU metaphysics or an intelligent Outside. The incoming signal is a deterministic, externally supplied sequence that can be manipulated for causal controls. Underlying Numogram topology must be described exactly as committed; the META1 runner's edge list contains `3>6`, but not `6>3`. Therefore **no literal 3⇄6 Warp circuit** is present in the frozen graph. Warp terminology is a candidate interpretive analogy, not a transition proven to occur.

## What must be separated

1. **Encounter:** the same deterministic developmental system receives an exceptional incoming sequence during a bounded epoch, or a matched baseline/counterfactual.
2. **Incorporation:** code V, surface S, deep D, and learned receiver-state differences can persist once ordinary identical input resumes.
3. **Capacity:** when confronted with a fresh, independently held-out *challenge*, the post-encounter system can do something measurably different from controls, beyond retaining a non-causal trace.
4. **Selection / survival:** if a system dies, terminates or never reaches a challenge, report failure, never silently drop or restart it.

## Stage structure — four epochs, identical forks

| Epoch | Meaning | Inputs | What may adapt |
|---|---|---|---|
| G — genesis | Build the same initial lineage/house state once per world | Registered deterministic shared genesis | Frozen original Studio 01–04 development |
| E — encounter | Present a finite outside intervention | Treatment-specific 256-tick sequence | Original V/S/D and receiver (if arm enables it) |
| W — washout | Remove special signal and resume shared ordinary inputs for 2,048 ticks | Byte-identical per-world ordinary signal across arms | Frozen substrate; receiver according to arm |
| C — second encounter | Hold-out challenge probes **without fitting or adaptation of the receiver during the probe** | Same independently derived held-out challenge for each paired arm | Only the original substrate within frozen challenge; learned receiver parameters snapshotted before challenge |

The epoch numbers are **engineering design values** pending runner feasibility and pre-registration; freeze after tests on separate QA fixture seeds, never tune them after inspecting scientific outcomes.

### Candidate encounter contrast

- **E1 structured Outside:** 256 event labels derived deterministically from world seed and *encounter-only* domain, following a predeclared repeating perturbation motif with out-of-pattern interruptions. Source input must enter through the **same canonical `runtime.step(input)` pathway**, not a secret choice bonus or rewritten graph.
- **E0 matched neutral input:** 256 world-specific neutral strings, fixed and distinct across ticks, with equal number, encoding length and alphabet constraints.
- **ER scrambled structure:** same exact collection of 256 E1 message bytes, permutation-shuffled according to a separately pinned seed. Controls message content/frequency while disrupting order; not entropy/effect matched unless independently demonstrated.

Each encounter arm is forked from an identical full state with equivalent life/clock counters. E0/E1/ER differ only in their 256 input strings. Downstream W and C inputs are **identical** for paired arms. The untreated world is a legitimate causal counterfactual.

**Design warning:** A string entering the runtime may have different immediate choice effects even if source labels have matching length/entropy. The mechanism must log decoded input zone, score at candidate exits, resulting transition and state; equal string lengths are not equivalent causal doses. Determine and pin the input decoding before registration.

## Distinguishing memory from response: two clones at the second encounter

At the end of W, save full receiver state, code V, house S/D and *complete* substrate state. Create exact, separate challenge clones:

- **Carry:** develop E→W history into C unchanged.
- **Memory reset:** replace only the documented adjustable learned receiver state with the pre-encounter state; keep substrate and house unchanged. This isolates receiver-specific contributions.
- **House/code reset:** replace only house S/D and lineage V with their G snapshot; keep receiver state unchanged. This isolates developmental organisation carried in environmental/code memory.
- **Double reset:** reset both layers for a negative incorporation control.

These are counterfactual *interventions*, not equivalent biological lineages. They require complete-state fork/restoration parity tests. In the frozen META1 runner `stateDigest` is only lineage/zone/counters, NOT a full substrate digest; full state export must be validated before any comparison is admitted.

## Experimental outcome ladder

- **Technical manipulation check:** the source signal entered the registered input pathway; transition changes, zone opportunities and duration are logged.
- **Persistence:** E1 vs E0 causal-state difference survives 2,048 common-input washout steps, with explicit attribution to V/S/D/receiver components.
- **Primary future-competence candidate:** on the *same* previously unseen challenge C, report complete seven-part vector: deaths; unique directed edges; encounter interruptions; capacity to return to a prior viable route; mean code/house change; time to first goal-related transition; and continued viability. Do not collapse a seven-component vector into an unregistered post-hoc win.
- **Comparison needed for claim:** predeclared single primary metric and direction, exact paired test, uncertainty interval, and registered independent worlds. These remain unresolved and **must be pinned before any scientific run**. A meaningful capacity increase requires both detectable carry-over and improved held-out performance relative to a matched non-encounter condition; merely selecting a different transition does not qualify.

## Control of the sense organ
