This bundle contains the sealed observer source/evidence archive, the complete cohort manifest, audits, summaries, report, figure and scripts. Full original cohort files are supplied separately in numbered ledger-part ZIP files. Extract SEALED_OBSERVER_EVIDENCE.zip into a working directory; then extract the metadata in cohort_runs/ and every ledger part into that same directory. SHARD_INDEX.json identifies each part and its SHA-256. Run `python -B analysis/corrected_archive_audit.py --lab . --run-dir cohort_runs/confirmatory_20261115 --output reconstructed_archive_audit.json` to verify the reconstructed archive. The original sealed archive validator compares host lists in iteration order and flagged ten populations on JSON restoration; the corrected validator compares host identities while preserving per-host route order. Both audit records and all observational analysis and figure scripts are under analysis/.
