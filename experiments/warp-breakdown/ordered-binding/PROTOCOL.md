# Final Warp round: order-preserving memory binding

## Question and decision rule

After exposure to A→B→C, a displacement and an interfering A→C→B sequence, can an engineered Amelia 3/6 House-to-gate pipeline correctly recover the original relative order of B and C? Is its accuracy statistically higher than both an adapted 2/7 loop and a direct recurrent comparator under the same task-facing capacity, inputs, perturbation and decision budget?

This single held-out test declares `REGISTERED_WARP_ORDER_BINDING_ADVANTAGE` **if and only if** 3/6's mean original-order accuracy in switched histories is strictly higher than both comparators, and both one-sided paired sign-flip tests have Holm-adjusted p **strictly below 0.05**, correcting together over those two tests. Otherwise the classification is `NO_REGISTERED_WARP_ORDER_BINDING_ADVANTAGE`. There is no extra practical-effect threshold. The p-values test zero paired difference, with the eight reused origins as the units; the later shared world input makes independence imperfect.

The two-timescale memory, its order decoder and the House-to-gate relay are deliberately engineered. Positive accuracy tests this pipeline, not the spontaneous invention of the representation. Neither noncommutative input order nor any result proves a native non-Abelian or non-Euclidean Warp, consciousness, independent Outside information, or autonomous code rewriting.

## Balanced histories and hidden answers

Use the eight historical Oracle-origin checkpoints and four fresh paired seeds per origin. For each seed select a physical anchor token A from {0,1,2}; the remaining physical tokens form a pair. Present all four combinations of two possible original orders and two possible second orders, with the same anchor and symbol counts. In the switched subset, `old=A,B,C` is followed by `new=A,C,B`; the opposite physical labelling is also included. Unchanged histories are intermixed without a switch label. In particular, there are pairs with **the same second sequence** and the same symbols but opposite first sequences: this distinguishes old-order information from a shortcut that merely reverses or reads the latest sequence.

After the first three events, force each copy to each neutral zone {1,4,8}; old-zone eligibility is checked. Apply the same six-coordinate seed-derived perturbation to every arm and paired history at that zone: each coordinate is one of {-0.24,-0.18,...,+0.24}. Then expose the three-event second sequence. No probe answer or correctness feedback is supplied during either sequence or during testing.

Probe both old and new contexts: given the two non-anchor physical tokens as the left/right alternatives, choose which occurred first in that context. Present both left/right orders in separate clones of the same post-sequence state. The true order is scored only outside the controller. No control is given the hidden old/new order, switch indicator, target or counterfactual response. The old-order accuracy on **switched histories after displacement and second-sequence exposure** is the sole primary endpoint. New-order and unchanged-history accuracy are reported separately. Chance for a fixed left/right response is exactly 50% under the paired alternatives; identical symbol histograms cannot distinguish the paired old histories.

## Concrete pipeline and controls

Each host is an actual copy of the pinned Oracle state with its original Numogram runtime and House learner. `warp` uses native Zones 3/6; `matched27` uses the earlier adapted 2/7 loop; `direct_host` uses the same 3/6-host copy but decodes directly rather than allowing its gate to choose the response. Its direct recurrent comparator has two three-coordinate cells and uses the identical input recurrence and six House values. A six-scalar standalone recurrent comparator without an Oracle host is also reported; it is not the primary direct comparison. The direct recurrence updates its state from observations; it is a hand-specified, analytically decoded recurrent learner, not a gradient-trained RNN.

All three hosted arms have **10 Numogram zones**, **30 values in each of House V, S and D**, two task-focus nodes and six task-facing mutable House scalars. The one additional House key in the adapted control, `2>2`, is padded in the other two hosts and updated by the same adapter machinery. The matched graph has **24 open gates** and the native host **29**; equality of node count and House dimensions does not make the two full graphs isomorphic or prove equal total runtime memory. Each observed event and each hosted probe consumes exactly four scored gate transitions, including background transitions in the direct-host control. The standalone six-value recurrent control does not claim a Numogram transition count. Source reads, experimental writes and gate-score bonuses are additional engineered operations and are logged.

The six task slots are three V values on the focus pair's edges and three D values on the same edges: 3→3, 3→6, 6→3 for Warp/direct-host; 2→2, 2→7, 7→2 for matched 2/7. At experiment start only those six values are reset to zero. For each observed token j, update each of the three slow slots `V_i = 0.75*V_i + 0.5*[i=j]` and each of the three fast slots `D_i = 0.25*D_i + 0.5*[i=j]`, then allow four real native gate transitions and their ordinary runtime learning. The standalone recurrent baseline applies the same recurrence and perturbation but has no hidden Oracle dynamics.

For a probe the common analytic decoder reads the six values and the two candidate token IDs. Its fixed two-timescale linear inversion estimates the earlier/later relation in the requested old or new context without receiving either hidden sequence. In 3/6 and 2/7 the readout is delivered as a bounded parity bonus ±0.75 to the actual gate scoring; the chosen response is the parity of the last branching gate in four transitions. If no branching gate is selected, the predeclared fallback is action 0. Direct-host makes the same decoded choice directly while still executing four background host transitions; standalone makes the same decoded choice without a host. This is a hand-built information channel, not a demonstration that native gate geometry itself computed the decoder.

A same-state **reset** replaces only the six task slots with zero. A **donor exchange** replaces only those six slots with values from the opposite-old-order paired history with the same physical second sequence, anchor, shock zone and perturbation. All other state is hash-checked unchanged at the intervention boundary. The readout receives no record of which memory condition is present. Separate, predeclared secondary comparisons test 3/6 retained versus reset and retained versus donor using their own Holm correction over two tests; these assess whether the accessed memory matters, not Warp specificity.

## Aggregation and verification

For each origin, average the two left/right probes within a shock, the three shocks within a history, the two switched histories within a seed, and then the four seeds equally. Do the same for unchanged histories and new-context probes. Compare the eight origin means using exact paired sign flips and Holm adjustment as above. Report every arm, the full origin differences, primary adjusted p-values, reset/donor tests, both context accuracies, unchanged histories, standalone direct results and the host capacity and gate counts. Accuracy, not latency, is the primary outcome.

Seal the protocol, code, Oracle runtime and checkpoint hashes and a small implementation-only fixture before generating and committing a cryptographically random evaluation seed. The fixture checks arithmetic, resource dimensions and boundaries; it is not an additional scientific test. Run each origin twice and compare full records at 1e-12 tolerance. An independent Python audit regenerates the balanced histories and perturbations, validates input and decoder arithmetic, local gate-path legality, target labels and six-value intervention boundaries; it does not independently reconstruct native Oracle gate scores or every House update caused by the runtime. A separate audit rebuilds all accuracies from the raw choices and recomputes both Holm families. A known deliberately altered fixture must be rejected.

The trial uses synthetic sequences on the eight existing, partly dependent historical origins; it does not introduce a new world stream or modify the live receiver or live tablet. Exposing a reusable module in the experimental branch is not a tablet deployment.
