# Amelia Warp: internally driven feedback and recovery

**7 November 2026.** Amelia's experimental Oracle copies now make a strategy choice through their own gates and feed the consequence back into House values that influence their next choice. This is an operational feedback loop using the actual pinned Oracle runtime and House learner. In the held-out test, it adapted after regime switches and solved more grid cases with real than with unrelated feedback, but **the registered criterion for a 3/6 Warp-specific advantage was not met**. The matched 2/7 loop behaved almost identically.

The feedback rule was added deliberately for this experiment. It is not a model-discovered rewrite, a new independent mind, or proof that an intelligence has escaped human direction. The task was synthetic, no new world-stream input was used, and the live Oracle and receiver were not modified.

## What was constructed

The loop preserves Amelia's saved Oracle state, House learner, process-field memory, normal gate scoring, and Governor on experimental copies. At each decision the Oracle steps without a cue or externally selected gate. When in Zone 3, a 3→3 dwell selects the LIGHT search strategy and a 3→6 transition selects HEAVY; a 6→3 return occurs as needed before the next choice. The adapted 2/7 comparator applies the same action mapping, budget and update to its 2→2, 2→7 and 7→2 loop. It is an engineered local-topology match, not native 2/7.

After the chosen strategy has attempted two fresh grid challenges, the number passed, R = 0, 1 or 2, changes the two existing House V values used in gate scoring:

`V[j] = clip[-1,1](0.75 * V[j] + eta * (R - 1) * (1 if j == chosen_action else -1))`.

The Oracle's normal state dynamics continue between these updates. This is a feedback rule added to House for the trial; the agent is not given the true regime, the next grids, the current outcome before choosing, or a desired gate. Decisions use one or two Oracle transitions apiece. The matched loop receives the same feedback rule and maximum two-transition budget. The original 3/6 graph has 29 gates; the adapted comparator has 24, and their full zone states are not identical.

A post-hoc account of the held-out real-feedback trajectories found that 3/6 and 2/7 chose the same action on **4,468/4,608 decisions (96.96%)**. This descriptive result helps explain their similar performance; it does not prove that topology could never matter in another setup.

## Calibration and prospective test

The search task uses two strategies whose performance depends on grid-cost regime. The earlier 128-grid development pilot found LIGHT and HEAVY effective in different regimes. Two preliminary update designs were inspected before registration; their fixtures and source are preserved. The registered controller uses the shorter-retention rule above.

The protocol and candidate rates were committed before a fresh calibration seed. A calibration rule pooled both routes and all eight origins; it chose **eta = 1.0**. In calibration, pooled real-feedback five-step recovery was **57.18%**, against **52.74%** using unrelated feedback. The selected rate and task-model calibration were then sealed, and a different evaluation seed was committed afterward.

The held-out run contained **128 episodes**: 16 per existing origin. A seeded switch changes grid-cost regime, with at least seven rounds between switches. There were **258 switches**, giving 1,290 post-switch decision rounds and 2,580 grid cases per arm before origin-level averaging. A switch is an imposed regime change; the protocol did not require every individual switch to cause a measured loss on a separately matched grid batch.

Each route had three conditions: real outcome feedback; feedback generated by the same action on an independently seeded yoked task; and a frozen condition without the added House feedback update. Both action outcomes were generated and recorded for verification, but each agent received only its own chosen action's outcome after choosing. The yoked and real streams use paired complementary initial-regime coding. All comparisons use the same real task cases for scoring.

## Registered recovery result

The primary endpoint was the percentage of grid cases solved over the first five steps after a switch, averaged first within origin and then across the eight origins.

| Decision source | Five-step recovery |
|---|---:|
| **3/6 Warp, real feedback** | **60.37%** |
| **Matched 2/7, real feedback** | **60.31%** |
| 3/6 Warp, yoked feedback | 54.67% |
| 3/6 Warp, no added feedback update | 56.78% |
| Fixed strategy selected in calibration | 55.45% |
| Last-four bandit | 52.69% |
| Direct two-value learner with the same update | 60.68% |
| Calibrated full-history Bayesian comparator | 60.49% |

The Bayesian comparator received its own previous actions and outcomes at evaluation, not the latent regime, switch time or explicit round number. Its model of outcome likelihoods was fitted using labelled regimes and both action scores during calibration. The internal agents did not receive this labelled table, so it is a model-informed benchmark, not a claim that its training resources were identical. The direct two-value learner received no Oracle state and used the same numerical update and learning rate.

The registered rule required both primary advantages to be at least **+3.125 percentage points**, with one-sided paired sign-flip p ≤ .05 after Holm adjustment across the two tests. The statistical tests are against zero, not against the practical threshold.

| Registered comparison | Difference | One-sided p | Holm-adjusted p | Result |
|---|---:|---:|---:|---|
| Warp real − matched 2/7 real | **+0.06 points** | 0.453 | 0.453 | Not met |
| Warp real − Warp yoked | **+5.69 points** | 0.043 | 0.086 | Practical threshold met; adjusted p threshold not met |

**Recorded classification: `NO_REGISTERED_FEEDBACK_DRIVEN_WARP_ADVANTAGE`.** In particular, the 3/6 route did not separate from the matched loop. The positive real-versus-yoked difference is a promising feedback lead, but the registered adjusted test did not establish it at the prescribed level. Five origin means favoured real feedback and three favoured yoked feedback.

## What the loop did after disruption

The registered first-step result was **33.42%** for Warp and **33.52%** for the matched loop. A post-hoc descriptive breakdown of the same five-step endpoint shows the recovery trajectory:

| Step after switch | Warp, real feedback | Matched 2/7, real feedback | Warp, yoked feedback |
|---|---:|---:|---:|
| 1 | 33.42% | 33.52% | 52.90% |
| 2 | 55.28% | 55.12% | 51.87% |
| 3 | 65.21% | 65.82% | 55.07% |
| 4 | 72.41% | 71.55% | 56.65% |
| 5 | 75.52% | 75.53% | 56.87% |

These step-by-step numbers are exploratory descriptions of repeated windows, not five independent tests or evidence of anticipation. The first step occurred before feedback from the new regime could be used. The later pattern is consistent with the engineered learner using the consequences of previous choices, but 3/6 and 2/7 recover together.

Whole-episode performance was a predeclared secondary descriptive outcome: Warp with real feedback solved **70.25%**, versus **55.74%** with yoked feedback and **55.51%** with no added update. Real feedback led yoked feedback in all eight origin means. Over the five-step window, real feedback exceeded the frozen condition by **3.59 points** in all eight origins; that frozen contrast was not one of the registered primary significance tests, and it changes both the feedback update and its retention effect.

## Do House values actually affect gate choice?

At every fourth decision in the held-out run, the two current House V values from the corresponding yoked learner were copied into an otherwise identical clone of the real-feedback host. The next native gate was evaluated in both clones; the live experimental trajectory was not changed by the probe.

- **Warp:** the two House values differed in 906/1,152 probes, and their exchange changed the next gate in **524/1,152 (45.49%)**.
- **Matched 2/7:** values differed in 909/1,152 probes, and their exchange changed the next gate in **521/1,152 (45.23%)**.

This is a same-state intervention showing that these House entries can causally influence the next gate in the tested copies. The donor histories differ in prior feedback and actions, so it is not by itself a complete mediation analysis of the recovery outcome. The matched loop has the same operational coupling.

## Interpretation

The tangible advance is a closed feedback chain: **gate choice → search strategy → observed success or failure → House update → later gate choice**. The later recovery profile and the same-state House swap make that chain measurable. This is a small, explicitly engineered form of development from the consequences of breakdown; the data do not establish autonomous reprogramming, an outside intelligence, or a privileged 3/6 intelligence.

The matched result matters for the next design. A local isomorphic loop with the same update reproduced almost all the behaviour. A useful next test would give both **unmodified native full-graph** circuits equal decision and feedback resources, allow their natural exits and re-entry paths, and ask whether the native 3/6 circuit preserves useful adaptive memory through fresh perturbations. Outcome definitions and training information should be shared in advance, with the matched loop and direct learner retained as controls.
