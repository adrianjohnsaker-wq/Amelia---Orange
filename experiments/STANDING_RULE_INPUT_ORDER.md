# Standing rule: check the input's order before any world or Outside test (from 14 November 2026)

**Why.** Five sealed world studies (SXI-1R, NR-2, ANTENNA B, INGRESS II, STONE TAPE II) came back silent. All of them reduced
each world datum to its AQ digital root, which erased the world's order before it reached the Numogram or Amelia. Run on the
encoded stream itself, the same order test was already silent. That mistake negated weeks of work.

**The rule.**
1. **Check first.** Every world or Outside test runs its own order test on the encoded input stream itself, before any
   Numogram, body or Amelia, on data outside the test.
2. **Fix before registering.** If the encoded input carries no detectable order, the encoding is fixed before anything is
   registered.
3. **Make the check a stage.** The registration includes that input stage (S0) as a manipulation check. A sealed test whose
   input stage comes back silent is **void, not a null**.

**What follows it.** WE-1 and WE-2 (stage S0) follow it. ND-3 (sealed 9 Nov, digital-root encoding) predates the rule. It runs
as registered and is read with its input stage reported.
