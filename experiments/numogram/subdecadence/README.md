# Pandemonium 45-card action-match experiment

The registration defines a project adaptation of Lemurian Subdecadence using the 45 Matrix entries as distinct cards. It is exploratory and does not modify Amelia's substrate.

- `REGISTRATION.md`: frozen actions, deck rules, scoring, seeds, readouts, limits.
- `cards.json`: complete 45-card deck derived from the existing verified Matrix catalogue.
- `cards.html`: print-ready card faces, nine per sheet.
- `suggested-actions.json`: action phrases with A1Z26 targets.
- `run.mjs`: deterministic simulator; one Set-1/Set-2 deal per replicate.
- `runs.csv`, `results.json`, `SHA256SUMS.txt`: raw run records, summary, and digest.

Source distinction: the CCRU Matrix has 45 entity identities; published Subdecadence describes a 40-card pack (36 cards plus four zero-valued Queens) with value-pairs summing to nine. This experiment combines the user-specified 45 entity card construction with that scissor relation as a clearly labeled project adaptation. See [CCRU Pandemonium](https://www.ccru.net/digithype/pandemonium.htm).
